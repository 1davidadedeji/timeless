# Timeless v1 Brain Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a local Timeless brain on the Mac: SQLite source of truth, dual-device web dashboard/chat, daily gate, rituals, meeting halt, opportunity approvals, mail-action stubs, ingest endpoints — $0, no paid APIs.

**Architecture:** One FastAPI process binds to LAN/Tailscale, serves `web/`, and mutates SQLite via a small store layer. Sensors (ActivityWatch, screenpipe, Android) POST into ingest later; v1 includes URL ingest + phone event POST so those adapters have a home. Ollama is optional for chat and praise.

**Tech Stack:** Python 3.12, FastAPI, uvicorn, stdlib sqlite3, pytest, httpx, vanilla HTML/JS in `web/`.

## Global Constraints

- Name: Timeless. Personal use only.
- Cost: $0. No OpenAI/Anthropic/screenpipe subscription.
- Secrets never in SQLite; Keychain later. No keylogger.
- Opportunity life-state from automation only via `pending_approvals` (default).
- Empty daily plan rejected. No Skip today.
- Meetings: overlay until `join` or `im_in`; else `missed` at end.
- HTTP not advertised on public internet; default bind `127.0.0.1` with `TIMELESS_HOST` override for LAN/Tailscale.
- Tests: `pytest` from repo root.
